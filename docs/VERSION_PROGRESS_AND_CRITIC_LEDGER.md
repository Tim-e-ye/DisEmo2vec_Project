## 一、 全局追踪铁律与版本演进总纲

1. **强制时间窗前移（`2024 -> 2025 -> 2026`）**：
   - 全面淘汰 2023 年及更早的过时基线对比；
   - **`2024`（开源基座母板）**：仅作 `Baton 0` 结构死穴解剖锚点（音频 `emotion2vec` ACL'24、视觉 `Ferret` ICLR'24、逻辑 `MCTS-CoT` 2024）；

   - 每一把新入库锤子必须通过 **① 张量形状守恒**、**② Padding/无效区 `-1e9` 掩码零泄漏（`<1e-5`）**、**③ 数值防爆锁（`LayerNorm` / `clamp_min` / 能量包络锚定）**、**④ 微门控残差初始化（`sigmoid(-2.0 ~ -2.4)` 保护冻结流形）**。

   - **第一轨（三大独立试验田 `Baton 0 -> Baton 1 -> Baton 2 -> Baton 3`）**：如实记录每一棒暴露的流形破坏、组合掉点或算力膨胀问题，以及下一棒靶向锤子的实测净增益 $\Delta$；
