# 如何从代码层面对着钉子找锤子 V1.3（三层卡槽架构 + 4卡 A10 三大防坑细节 + 两大微观张量保护终极版）

> **版本演进历史（供 `0-Arch-Meta` 架构实战过程记录子会话追溯）**：
> - **`V1.1`（模块化骨架版）**：确立 **「独立卡槽文件夹（`hammer_slots/`） + 统一总控入口（`hammer_modules.py`） + `forward()` 开关调用 + 单变量试锤脚本」** 三层架构；
> - **`V1.2`（4 卡 A10 梯度与流派加固版）**：合入 **三大工程防坑细节**（① 预训练 `forward_student_backbone` 与评测 `extract_frozen_representations` 分离防断梯度；② H3 `frame_weights` 复用于 $\mathcal{L}_{\text{Frm}}$ 且 Teacher 产出强制 `.detach()`；③ H1 在线 GPU 张量与离线音频副本双兼容）；
> - **`V1.3`（微观张量边界终极定稿版）**：在 `V1.2` 基础上合入真正敲代码进 `.py` 时的 **两大微观张量保护叮嘱**：
>   1. **【叮嘱 1：H3 `padding_mask` 对齐与真实有效帧长 $N_{\text{valid}}$】**：在 `slot_h3_pooling.py` 中将短句末尾 Padding 帧的打分 $s_i$ 设为 `-1e9`（使 Padding 处 $w_i = 0$），且在 $(1 + N_{\text{valid}} \cdot w_i)$ 中取每句话的真实有效帧数 $N_{\text{valid}}$，防止短句因拼了长 Padding 而权重失真；
>   2. **【叮嘱 2：H1 `offline_wav_1C` 的 Batch 内独立随机采样】**：在 `slot_h1_view.py` 中使用形状为 `(B, 1, 1)` 的布尔掩码执行 `torch.where(mask, offline_pert_frames, source_frames)`，让同一个 Batch 里的不同样本独立掷硬币，使梯度方差更稳。

## 二、 这三层是怎么配合工作的？（直接看 V1.3 真实代码）

### 1. 底层：`models/hammer_slots/` 里的 3 个独立卡槽文件（每个候选锤头只是一个 15 行小函数）

以卡槽 H3 [slot_h3_pooling.py](file:///D:/Code/VibeCode/Antigravity/Project/DisEmo2vec_Project/models/hammer_slots/slot_h3_pooling.py) 为例，**每一个从文献里看来的新公式，都只是一个只管输入 `(B, N, 768)`、输出 `(B, 768)` 的独立小函数**，并在内部加上了 `padding_mask -> -1e9` 与 `.detach()` 保护：

```python
# 位于 models/hammer_slots/slot_h3_pooling.py (salience_pooling_3A 核心片段)
# 1. 句内背景均值 y_bar 仅在真实有效帧 (~padding_mask) 上求平均
valid_f = (~pad_bool).to(y_t.dtype)  # (B, N)
n_valid = valid_f.sum(dim=1, keepdim=True).clamp_min(1.0)
y_bar = torch.sum(y_t * valid_f.unsqueeze(-1), dim=1, keepdim=True) / n_valid.unsqueeze(-1)

# 2. 有声门控 × 离群度打分，并将 Padding 帧打分设为 -1e9（叮嘱 1：使 Padding 处 w_i = 0）
salience_s = torch.sigmoid(frame_energy) * torch.norm(y_t - y_bar, p=2, dim=-1)
scaled_logits = (salience_s / temperature_tau_s).masked_fill(pad_bool, -1e9)
weights_w = F.softmax(scaled_logits, dim=-1).masked_fill(pad_bool, 0.0).detach()
target_utt = torch.sum(weights_w.unsqueeze(-1) * y_t, dim=1).detach()
```

同样，在卡槽 H1 [slot_h1_view.py](file:///D:/Code/VibeCode/Antigravity/Project/DisEmo2vec_Project/models/hammer_slots/slot_h1_view.py) 的 `h1_offline_wav_1C` 中，使用 `(B, 1, 1)` 掩码实现 Batch 内样本独立掷硬币（叮嘱 2）：

```python
# 位于 models/hammer_slots/slot_h1_view.py (h1_offline_wav_1C 核心片段)
mask = torch.rand(bsz, 1, 1, device=student_x.device) < 0.5
out = torch.where(mask, offline_pert_x, student_x)  # 同 Batch 内一半样本用变声、一半用原声，梯度方差更稳
```

### 2. 中层：[hammer_modules.py](file:///D:/Code/VibeCode/Antigravity/Project/DisEmo2vec_Project/models/hammer_modules.py) 汇总并在 `forward()` 中用 3 个开关调用

在 `hammer_modules.py` 的 `PluggableDisEmo2vecFrontend.forward()` 里，主干源码只用 4 步清晰串联 **H1 $\rightarrow$ H3 $\rightarrow$ Student 主干 $\rightarrow$ L_Frm + H2**：

```python
# 位于 models/hammer_modules.py (Line 176-225)
# 1. [卡槽 H1 开关: --view_type] 兼容 GPU 在线张量微扰与离线副本 Batch 内独立掷硬币（细节 3 + 叮嘱 2）
student_x, h1_meta = self.h1_slot(
    source_frames,
    frame_energy_std=frame_energy,
    offline_pert_x=offline_pert_frames,
    view_type=self.cfg.view_type,
)

# 2. [卡槽 H3 开关: --pooling_type] 含 padding_mask -1e9 保护，强制 .detach() 封死 Teacher 梯度（细节 2 + 叮嘱 1）
target_utt, frame_weights, h3_meta = self.h3_slot(
    target_layer_results,
    frame_energy_std=frame_energy,
    attn_weights=attn_weights,
    padding_mask=padding_mask,
    pooling_type=self.cfg.pooling_type,
)
target_utt = target_utt.detach()
frame_weights = frame_weights.detach()

# 3. [预训练 Student 主干前向传播 — 全程保留梯度 requires_grad=True！（细节 1）]
x_frm_emo, z_utt_emo, z_utt_cont = self.forward_student_backbone(student_x)

# 4. [卡槽 H3 (1 + N_valid * w_i) 帧损失 + 卡槽 H2 开关: --disentangle_type]（细节 2 + 叮嘱 1）
loss_frm = self.h3_slot.compute_salience_weighted_frame_loss(
    y_student_frames=x_frm_emo,
    y_teacher_frames=target_layer_results.detach(),
    frame_weights=frame_weights,
    mask_indices=mask_indices,
    padding_mask=padding_mask,
)
h2_meta = self.h2_slot.compute_disentangle_losses(
    z_emo=z_utt_emo,
    z_cont=z_utt_cont,
    y_teacher_sal=target_utt,
    p_hubert_target=p_hubert_target,
    disentangle_type=self.cfg.disentangle_type,
)
loss_total = loss_frm + h2_meta["loss_total_h2"]
```

### 3. 顶层：日常单变量试锤（[run_single_hammer_trial.sh](file:///D:/Code/VibeCode/Antigravity/Project/DisEmo2vec_Project/scripts/run_single_hammer_trial.sh)）

日常做实验时，只需要在命令行里拨动这 3 个开关（每次只动一个变量，训 25 轮自动送进 `eval_all_8_metrics.py` 称重）：

```bash
# 第一轮：只开 H3 的候选锤头 3A（其它两个卡槽保持原版关闭）
bash scripts/run_single_hammer_trial.sh --pooling_type salience_3A

# 如果 3A 没涨分，1秒钟切换测候选锤头 3B：
bash scripts/run_single_hammer_trial.sh --pooling_type attn_rollout_3B

# 假设 3A 涨分显著，锁死 --pooling_type salience_3A，再打开第二个卡槽开关 H2 测 2A：
bash scripts/run_single_hammer_trial.sh --pooling_type salience_3A --disentangle_type clean_proj_2A

# 再叠加卡槽 H1 测在线共振峰微扰 1A（或离线音频副本 1C）：
bash scripts/run_single_hammer_trial.sh --pooling_type salience_3A --disentangle_type clean_proj_2A --view_type vtlp_1A
bash scripts/run_single_hammer_trial.sh --pooling_type salience_3A --disentangle_type clean_proj_2A --view_type offline_wav_1C
```

## 三、 4 卡 A10 实战训练必查的「3 大防坑细节 + 2 大微观叮嘱」全景清单

| 编号 | 所在模块 | 要防范的具体工程事故 | V1.3 落地代码方案 |
| :--- | :--- | :--- | :--- |
| **🚨 细节 1**<br>防梯度断流 | `hammer_modules.py` | 预训练 `forward()` 若误调带 `no_grad()` 的冻结提取函数，会导致 Student 参数与 10 个 Chunk Tokens 训 25 轮纹丝不动 | 预训练调 `forward_student_backbone()`（全程 `requires_grad=True`）；下游评测调 `extract_frozen_representations()`（包裹 `torch.no_grad()`） |
| **🚨 细节 2**<br>帧权重复用与 Teacher `.detach()` | `slot_h3_pooling.py`<br>`hammer_modules.py` | 1. 局部帧损失 $\mathcal{L}_{\text{Frm}}$ 若不加权，80% 精力仍浪费在平淡帧；<br>2. Teacher 输出若不 `.detach()`，梯度会倒灌涂改 Teacher | 1. 将 $w_i$ 传给 $\mathcal{L}_{\text{Frm}}$ 乘上 $(1 + N_{\text{valid}}\cdot w_i)$；<br>2. 对 `target_utt`、`frame_weights`、`target_layer_results` 全部强制 `.detach()` |
| **🚨 细节 3**<br>H1 在线与离线双兼容 | `slot_h1_view.py` | 纯 CPU 声码器（如 Praat/WORLD）若放在训练时实时算，会卡死 4 张 A10 显卡 | `h1_slot` 同时支持 GPU 在线实时张量变换（`vtlp_1A`/`channel_drop_1B`）与 DataLoader 读入 `(clean_wav, pert_wav)` 离线副本二选一（`offline_wav_1C`） |
| **🔍 叮嘱 1**<br>Padding 掩码 `-1e9` 与 $N_{\text{valid}}$ | `slot_h3_pooling.py` | 同 Batch 内短句末尾拼的空白 Padding 帧会偷走 Softmax 权重 $w_i$，且总宽度 $N$ 会虚高短句的加权倍数 | 1. 算 Softmax 前对 `padding_mask == True` 的位置将 $s_i$ 设为 `-1e9`，使 Padding 处 $w_i = 0$；<br>2. 加权系数使用每句真实有效帧数 $N_{\text{valid}} = \sum(\sim\text{padding\_mask})$ |
| **🔍 叮嘱 2**<br>Batch 内样本独立掷硬币 | `slot_h1_view.py` | 若整个 Batch 统一掷一次硬币（全用变声或全用原声），步间梯度方差大、训练抖动 | 使用形状为 `(B, 1, 1)` 的布尔掩码 `mask = (torch.rand(B, 1, 1, device=x.device) < 0.5)` 配合 `torch.where(mask, offline_pert_frames, source_frames)` 逐样本独立采样 |
